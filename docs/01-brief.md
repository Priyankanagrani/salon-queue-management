# Salon Queue Management System — Project Brief

## 1. Problem Statement
During busy hours and weekends, customers often spend a long time waiting at salons without knowing their queue position or estimated waiting time. Manual queue management can create confusion about customer turns and barber availability.

This system aims to make salon queue management organized, transparent and convenient.

## 2. Target Users
1. **Customers:** Join the queue, select services and preferred barbers, and track their turn.
2. **Receptionist:** Manage the queue, add walk-in customers, call the next customer and handle no-shows.
3. **Barbers:** View assigned customers, start and complete services, and update availability.
4. **Salon Owner:** Manage services, prices, barbers on duty and queue settings.

## 3. Must-Have Features
1. Customers can join the queue using their phone, select services and choose a preferred barber or Any Barber.
2. Customers can track their token number, queue position and estimated waiting time, with Start Coming and It's Your Turn alerts.
3. Receptionists can add walk-in customers, call the next customer, mark no-shows and cancel queue entries.
4. Barbers can view their current customer and use Start and Done actions, with an option to mark themselves On Break or Available.
5. A waiting-area TV display shows which customer is being served by each barber and the next five tokens.
6. Owners can manage services, service duration, prices, barbers on duty and online queue opening or closing.

## 4. Features Outside the Project Scope
- Online payments.
- Future-date appointment booking.
- SMS or WhatsApp notifications.
- Loyalty and reward programmes.
- Multiple salon branches.

## 5. Look and Feel
A premium, modern, mobile-first salon interface with:
- Dark charcoal background (#1F2937).
- Gold accents (#D4A017).
- Clean layouts and rounded cards.
- English and Gujarati language support for all interface labels.
